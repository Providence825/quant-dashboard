- 四智能体选股流水线 → 四智能体市场解读教学流水线（市场环境/策略标注/风险评估/教学解读）
- 新增四大策略分类卡片（趋势跟踪/情绪周期/基本面筛选/板块轮动，与后端 `strategy_meta.py` 一致），含风险标签
- 移除候选股拉取（`/api/screen/candidates` 前端不再调用；后端本就 403 禁用）

- 合规弹层、投教学院、情绪卡片、测评结果等 30+ 处文案投教化
- 保留 s-verify（run#117 真实回测验证）、s-school（投教学院）、s-alloc、s-check

**备份**：旧量化版前端 → `static/index_quant_backup.html`（26KB）。  
**原版完好**：`huitoudun.html` / `huitoudun_v2.html` / `htd_173251.html` 时间戳 14:14 未动，工行杯照常用。

**验证（5002 实测）**：HTTP 200；标题正确；慧投盾/工行/ICBC/私享投顾 全部 0；`候选股`仅存于合规注释、`推荐个股`仅存于"不推荐个股"声明；`/api/strategy/categories` 200（四类+风险色）；`/api/screen/candidates` 403。

**交互失效修复（2026-09-26 傍晚）**：首次打开页面点击"开始适当性测评/先随便看看"无反应。根因：`renderPeerComparison()` 被空函数化时原函数体残留在顶层作用域，其中 `const holds` 与顶层 `let holds=[]` 重复声明 → 整个 script 块 SyntaxError → 所有全局函数未定义、全部点击失效。已删除悬空代码块（约73行），node 语法检查 + Edge 无头加载双重验证通过。**注意：`huitoudun_v2.html` 原版存在同一 bug**（该 bug 是更早会话在原版上留桩时引入、随复制带入 index.html 的），但工行杯入口 `/htd` 指向的 `huitoudun.html` 是干净的，v2 文件未接路由、属潜伏问题，待用户决定是否修复原版。

> 注：下文一、二节中涉及 `static/js/screener.js`、`static/js/dashboard.js` 的条目为旧量化版前端的改造记录，新 index.html 为单文件版不再引用这些 js 文件，相关结论以本节为准。
